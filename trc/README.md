# TRC Landing Portal

An open-source diagnostic interface template built to log client runtime environments for troubleshooting and responsive UI sizing layout analysis.

## Features
- Automated Client Environment OS type check.
- Standard ISO 8601 formatting for telemetry execution tracking.
- Asynchronous API payload forwarding targeting specialized webhook listeners.

## Deployment Details
To host this immediately using GitHub Pages:
1. Push these files directly to a new repository on your GitHub account.
2. Navigate to **Settings** > **Pages** inside your repository.
3. Select your primary branch as the deployment source and save.
